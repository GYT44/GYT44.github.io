Research · project lead · 2023–2025

TDOA Acoustic Source Localisation

Led a distributed Raspberry Pi microphone-array project for stored-grain pest monitoring. Integrated PTP clock synchronisation, ALSA-based audio capture and MATLAB signal-processing pipelines using STFT, cross-correlation and TDOA localisation.

Reported results: 0.2 ms time synchronisation and 0.25 m two-dimensional localisation accuracy.

Embedded robotics · 2024

Autonomous Figure-Eight Navigation Robot

Built an autonomous mobile robot around the MSPM0G3507 microcontroller, integrating grayscale sensors, an OpenMV vision module and an HWT101 gyroscope for track following and motion feedback. Developed Linux-based embedded software components and implemented dual-loop PID control for both speed and steering.

Reported result: stable figure-eight line following with obstacle avoidance, fixed-point stopping and a best single-lap time of 15.12 s.
